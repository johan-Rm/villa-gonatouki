## INSTALLATION

::: Requirements :::
                                        
* Node :      16.14.2
* Yarn :      1.22.19

--- 
<br/>

Récupérer les resources

```bash
unzip $PATH_RESOURCES/nuxt-modern-website/resources.zip -d ./static
```

Récupérer les datas

```bash
unzip ./backup.zip
```

Éditer le fichier .env

```bash
cp .env.example .env && nano .env
```

Installer les dépendances

```bash
yarn install
```

<br/>

## UTILISATION

```bash
yarn dev
```
